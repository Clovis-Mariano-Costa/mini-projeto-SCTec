# Develop — Consolidação do SkillMatch JS

Mini-Projeto Avaliativo do Módulo 01 do curso de Programação Front-End React do IFSC.

Projeto: **SkillMatch JS — Simulador de Compatibilidade com Vaga Front-End Júnior**

---

## Objetivo da branch Develop

A branch `Develop` é utilizada para reunir e revisar as funcionalidades desenvolvidas nas diferentes etapas do projeto antes da versão final.

Nesta fase foram consolidadas as implementações das etapas anteriores:

- perfil do candidato;
- vagas;
- cálculo de compatibilidade;
- classificação;
- habilidades faltantes;
- melhor vaga;
- recomendação de estudo;
- métodos de array;
- classes;
- herança;
- callback;
- closure;
- Promise;
- async/await;
- tratamento de erros;
- estrutura de repetição;
- organização da saída no console.
