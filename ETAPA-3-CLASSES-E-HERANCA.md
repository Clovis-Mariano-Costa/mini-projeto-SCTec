# Etapa 3 — Classes e Herança

Mini-Projeto Avaliativo do Módulo 01 do curso de Programação Front-End React do IFSC.

Projeto: **SkillMatch JS — Simulador de Compatibilidade com Vaga Front-End Júnior**

---

## Objetivo da etapa

A terceira etapa do projeto teve como objetivo aplicar conceitos de Programação Orientada a Objetos e funções avançadas estudadas no módulo.

Nesta etapa foram implementados:

- classe principal;
- construtor;
- atributos;
- métodos;
- uso de `this`;
- classe filha;
- herança;
- `super`;
- callback;
- closure;
- integração entre callback e closure.
