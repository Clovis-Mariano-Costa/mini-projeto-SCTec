# Etapa 1 — Perfil e Vagas

Mini-Projeto Avaliativo do Módulo 01 do curso de Programação Front-End React do IFSC.

Projeto: **SkillMatch JS — Simulador de Compatibilidade com Vaga Front-End Júnior**

---

## Objetivo da etapa

A primeira etapa do projeto tem como objetivo criar os dados básicos que serão utilizados posteriormente pelo sistema para calcular a compatibilidade entre uma pessoa candidata e diferentes vagas.

Nesta etapa foram desenvolvidos:

- o perfil do candidato;
- a área de interesse;
- a lista de habilidades;
- o tempo de experiência;
- o array de vagas;
- três vagas fictícias;
- os requisitos de cada vaga;
- pesos diferentes para os requisitos.
