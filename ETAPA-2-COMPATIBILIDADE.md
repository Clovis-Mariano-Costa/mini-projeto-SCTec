# Etapa 2 — Compatibilidade

Mini-Projeto Avaliativo do Módulo 01 do curso de Programação Front-End React do IFSC.

Projeto: **SkillMatch JS — Simulador de Compatibilidade com Vaga Front-End Júnior**

---

## Objetivo da etapa

A segunda etapa do projeto teve como objetivo desenvolver a lógica responsável por comparar o perfil do candidato com as vagas cadastradas.

Nesta etapa foram implementadas as funcionalidades de:

- calcular o percentual de compatibilidade;
- classificar a compatibilidade;
- identificar habilidades faltantes;
- encontrar a melhor vaga;
- criar recomendação de estudo;
- aplicar métodos de array.
